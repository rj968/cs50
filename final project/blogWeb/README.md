## Description

blogWeb provides a simple and minimalistic solution to your journalling problems.

### How to use

- **Home**: This page gives information about the website. It also allows users to login/register.
- **Blog**: This is the page where the user can write, view and edit their blog. It stores the blog into our database upon submission for later use.
- **Archives**: Here users can view a list of all of their past blogs and also search through them by their name. They can also delete the blog if they wish to here.

### Why this project

This project aims to create a simple daily journaling/blogging website for users. It was created as a submission for the final project of CS50x 2025. This project was chosen as a means to showcase all that I have learned in CS50x and expand upon it. It makes use of various concepts from Web-development and database management.

### What problem does this solve

blogWeb aims to provide the user with a minimalistic way to express themselves and write down their thoughts however they like while maintaining complete confidentiality and privacy.
